# Decompiled native reference only

These files are machine-recovered Java representations of the pinned code 601 DEX, not the lost authored Kotlin/Java and not a buildable Android source tree.

See `../../docs/NATIVE-COMPATIBILITY.md` and `../../evidence/native-recovery/` for exact provenance, original-to-renamed class mapping, all warnings/failed-method inventory, command records, and checksums. All 254 K5/L5/app-package classes are included; dependency constants and five raw fallback outputs are separate directories. Preserve the original DEX alongside this reference. Never copy a decompiler placeholder, unresolved type, or malformed control flow into executable app code.
